# 静态住宅代理接入

网关通过标准 HTTP Basic Proxy 认证支持普通 HTTP 请求与 HTTPS CONNECT 隧道。每个静态租约拥有独立用户名/密码，并永久绑定该租约分配的一个节点。

## 接入

在用户前台「静态住宅 → 已购 IP」中查看接入信息。使用页面给出的中转代理主机、端口、用户名和密码，不使用网站邮箱密码或供应商主账户。

```bash
curl --proxy http://127.0.0.1:3128 \
  --proxy-user 'sip_租约用户名:租约密码' \
  https://example.com
```

上游可以是 HTTP 或 SOCKS5，网关客户端仍使用标准 HTTP 代理。HTTP/CONNECT 和上游认证都已在隔离测试环境中跑通。

## 固定出口与租期

- 不存在流量包认证、字节扣费、国家后缀选路、粘性会话池或随机轮询。
- 所有请求只使用该租约绑定的节点，上游失败返回错误，不切换到其他 IP。
- 校验租约到期时间、租约状态、用户状态及节点状态。停用与到期会阻断新请求和现有隧道；空闲隧道也定期复核状态。
- 续费延长原租约，保持 IP 与凭据。到期后如已转售，旧租约不能重新启用或续费抢回。
- 供应商节点应由运营方验证确为所需住宅出口。后台 TCP 检测仅判断端口可达，不证明住宅属性、地区或供应商认证正确。

## 错误与保护

| 状态 | 含义 |
| --- | --- |
| 407 | 凭据错误，或租约/用户/节点已停用、到期 |
| 403 | 目标为不允许访问的私网或保留地址 |
| 429 | 连接次数或并发超过限制 |
| 502 | 固定上游无法建立连接 |

默认阻止 localhost、私网、链路本地及云元数据地址；DNS 校验后使用已验证的地址连接上游，避免重绑定绕过。`GATEWAY_ALLOW_PRIVATE_TARGETS=true` 仅供本地测试，生产禁止。

生产网站 HTTPS 由 Caddy 提供，标准 HTTP 代理端口本身并不会因此得到 TLS。公网接入时应为代理链路落实 TLS 终止或受控网络，并使用页面实际展示的端口。不要把开发模拟环境直接暴露到公网。
