# 静态住宅代理运营

## 录入资源与定价

在管理后台「IP 资源」添加上游主机、端口、协议、认证及地区信息。支持 HTTP/SOCKS5，批量格式为：

```text
host,port,protocol,upstream_user,upstream_pass,country,region,city,isp
```

也支持每行 `host:port:user:pass`，使用导入窗口的默认国家和协议。不要加 CSV 表头；分隔符不能出现在字段内部，有此情况请使用单条添加。空行与 `#` 注释忽略，错误返回行号。IPv6 冒号格式使用方括号。

在「静态产品」设置每 IP 每租期的价格、天数、协议，以及可选国家/地区/城市/ISP 条件。可售库存来自符合条件的未分配启用节点，不由手工填写。没有真实库存时无法购买，平台不提供假 IP。

后台检测仅为 TCP 连通性检查，真实住宅属性、地理位置、认证和出口仍需使用供应商节点实际验证。

## 分配、到期与续费

每个租约独占一个节点。用户购买时同时完成库存分配、余额扣减、订单和账单，重复请求不重复扣款。单次最多 100 个。

租期从购买成功时计算。用户在已购 IP 列表查看和复制接入凭据、修改备注、导出结果及续费。续费从当前时间和原到期时间中较晚者继续延长；禁用租约不可自行续费绕过管理。已到期并重新分配的节点不能被旧租约抢回。

管理员在「IP 租赁」查看所有用户租约、启停及调整到期时间。临时禁用仍保留该节点至租约到期，不会提前转卖。分配期间不能更改节点接入地址、协议、主凭据；有租赁历史的节点不能删除，可停用。需更换供应商资源时先核实正在使用的租约并安排迁移，不应静默改变用户固定出口。

## 收款与账单

用户先充值余额，再购买或续费。真实回调经签名、商户、渠道、金额核验后入账；重复通知仅记一次。浏览器跳转、截图或用户口述不能代替商户交易核实。

人工到账前应在商户后台核对充值单、交易、金额及状态，再在充值对账页面写入备注确认。已到账不能改失败。余额调整会写独立流水，禁止负余额，避免同一充值既补单又加余额。

当前没有自动续费、自动退款、发票或商户主动查单流程，不应将余额调整当成原渠道退款。模拟支付环境在用户充值页和管理后台明确标识。

## 账号与备份

邮箱账号、用户禁用、密码修改和会话失效机制保留。用户账户菜单位于右上角。静态租约有自己的中转代理凭据，供应商主密码不对用户公开。

数据库备份与稳定的 `PROXY_CREDENTIAL_SECRET` 应一起安全保存；该密钥用于解密租约凭据，不能随意轮换。在线备份使用 `npm run backup -- /path/backup.db`，恢复时先停止写入，保留当前副本并核对数据库完整性与财务记录。
