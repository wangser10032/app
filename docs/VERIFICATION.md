# 静态住宅版本验收（2026-10-28）

## 本次变更

平台已改为静态住宅 IP 租赁：按 IP 数量和租期购买，每个租约绑定唯一固定上游，提供到期、续费、备注、接入凭据、复制与导出。不销售流量包，不按字节计费，不轮询或失败切换其他 IP。

前台移除流量购买、流量包、流量用量、侧栏充值、侧栏账号设置，以及营销首页、英文装饰标签、宣传口号、流量图表和大面积卡片。总览展示静态 IP 简表，右上角放余额、充值与账户菜单，静态住宅页分定价和已购 IP。

地区筛选现从当前账号真实已购租约生成，空数据时仅保留“所有地区”，没有硬编码的可选国家。独立于列表分页与当前搜索，并隔离其他用户数据。前后台使用白底、冷灰背景、克制的品牌蓝操作与 R 品牌标，已去除橙色品牌及导航强调。

后台改为静态产品、IP 资源与 IP 租赁管理。没有真实库存时显示空列表，不使用参考截图或演示地址冒充可售住宅 IP。
